# AGENTS.md

Instruções para agentes de IA que abrirem este repositório.

- **A pessoa só quer instalar ou usar o boringCode?** Não compile. Siga
  [docs/instalar-com-ia.md](docs/instalar-com-ia.md), que se resume a
  `curl -fsSL https://raw.githubusercontent.com/reesoousa/boringCode/HEAD/scripts/install.sh | bash`.
  O comando baixa o app assinado da última Release.
- **A pessoa quer mexer no código?** Leia o [CLAUDE.md](CLAUDE.md): stack, estrutura, como compilar e instalar
  a versão de dev (`scripts/install-dev.sh`), regras de git e decisões de produto.
